## Частина 3. Відповіді на питання за власним кодом

1. **Де у вашій `countItems` базовий випадок, якщо явного `if` там немає?**
   * **Пояснення:** Базовим випадком рекурсії виступає вузол, у якого список дочірніх елементів порожній (`node.Children` містить 0 елементів). У такому разі цикл `foreach` жодного разу не виконується, функція не здійснює подальших рекурсивних викликів і одразу повертає значення `1` (сам вузол).

2. **Чому ваша `find` знаходить «Масштаб», хоча в нього є вкладені пункти — покажіть рядок?**
   * **Пояснення:** Пошук перевіряє назву абсолютно кожного поточного вузла до обходу його дочірніх елементів. Це робить рядок:
     ```csharp
     if (node.Title == name) return true;
     ```
     Оскільки назва вузла «Масштаб» збігається із шуканою ще до запуску циклу по дітях, функція негайно повертає `true`.

3. **Чому «Довідка» теж є пунктом без вкладених, хоча стоїть на другому рівні?**
   * **Пояснення:** Термін «пункт без вкладених» (листок дерева) визначається наявністю дочірніх вузлів, а не рівнем вкладеності. Оскільки вузол «Довідка» має порожній список `Children`, він є листком дерева.

4. **Скільки разів викликалася `countItems` і чому саме стільки?**
   * **Пояснення:** Функція `countItems` викликалася **11 разів**. Це пояснюється тим, що рекурсивний обхід відвідує абсолютно кожен вузол дерева (усього в дереві 11 пунктів), і на початку кожного виклику виконується команда `callCount++`.

5. **Що зміниться у виводі `printMenu`, якщо спершу обробляти дітей, а вже потім сам вузол?**
   * **Пояснення:** Зміниться порядок друку (прямий обхід `Pre-order` зміниться на зворотний `Post-order`). Батьківські пункти друкуватимуться після своїх дочірніх елементів (наприклад, замість «Файл -> Новий -> Зберегти» виведеться «Новий -> Зберегти -> Файл»), а сам корінь «Головне меню» буде надрукований найостаннішим.
