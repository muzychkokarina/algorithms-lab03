# Лабораторна робота №14: Досяжність у графі

**Дисципліна:** Алгоритми та структури даних  
**Група:** ІПЗ-3/1  

## Мета роботи
На готовій моделі графа реалізувати обхід і застосувати його до двох задач: перевірити, чи досяжна одна зупинка з іншої, і відновити шлях між ними без використання матриць суміжності та сторонніх графових бібліотек.
